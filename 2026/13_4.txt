2. MiConteo
Input: dos strings, el segundo es sólo un caracter
Output: un entero con el número de veces que aparece el segundo string en el primer string
MiConteo("hola mundo","o") == 2
MiConteo("hola mundo","h") == 1
MiConteo("hola mundo"," ") == 1
MiConteo("hola mundo","r") == 0
MiConteo("hola mundo","!") == 0
MiConteo("hola mundo","") == 0
MiConteo("","A") == 0

def MiConteo(texto, caracter):
    contador = 0

    for letra in texto:
        if letra == caracter:
            contador += 1

    return contador


print(MiConteo("hola mundo", "o"))  
print(MiConteo("hola mundo", "h"))  
print(MiConteo("hola mundo", " "))  
print(MiConteo("hola mundo", "r"))  
print(MiConteo("hola mundo", "!"))  
print(MiConteo("hola mundo", ""))   
print(MiConteo("", "A"))            

salida: 2
1
1
0
0
0
0

3. GCcontent
Input: un string con una secuencia de ADN
Output: porcentaje de caracteres que son "G" ó "C"
GCcontent("ATGC") == .5
GCcontent("") == 0
GCcontent("AAAA") == 0
GCcontent("ATgc") == .5
GCcontent("GGCC") == 1

def GCcontent(adn):
    if len(adn) == 0:
        return 0

    contador = 0

    for letra in adn:
        if letra.upper() == "G" or letra.upper() == "C":
            contador += 1

    return contador / len(adn)


print(GCcontent("ATGC"))  
print(GCcontent(""))      
print(GCcontent("AAAA"))  
print(GCcontent("ATgc"))  
print(GCcontent("GGCC"))  

salida:
0.5
0
0.0
0.5
1.0

5. MiCapitalize
Input: un string
Output: un string que tenga la primera letra en mayúsculas

def MiCapitalize(texto):
    if texto == "":
        return ""
    return texto[0].upper() + texto[1:]


print(MiCapitalize("hola mundo"))

print(MiCapitalize("python"))

print(MiCapitalize(""))

salida: 
Hola mundo
Python

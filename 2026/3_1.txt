4. Explica qué hacen los métodos y da un ejemplo (2 puntos)
a. count() Cuenta cuántas veces aparece una letra, palabra o número dentro de un texto o una lista. texto = "Mi gato es un gato muy bonito"
print(texto.count("gato"))
# Resultado: 2
b. find() Busca una letra o palabra dentro de un texto y te dice en qué posición (número de casilla) empieza. texto = "Hola mundo"
print(texto.find("mundo"))
# Resultado: 5 (porque la 'm' está en la posición 5)
c. isdigit()Revisa si un texto está compuesto únicamente por números. Te devuelve True (Verdadero) si todos son números, o False (Falso) si tiene letras, espacios o signos. texto1 = "12345"
texto2 = "Año 2026"
print(texto1.isdigit()) # Resultado: True
print(texto2.isdigit()) # Resultado: False (tiene letras y un espacio)
d. replace()Cambia una letra o palabra por otra diferente dentro de un texto. texto = "Me gusta el café"
nuevo_texto = texto.replace("café", "té")
print(nuevo_texto)
# Resultado: "Me gusta el té"

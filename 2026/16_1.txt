4. Explica qué hacen los métodos y da un ejemplo: (2 puntos)

 a. count()
Sirve para contar cuantas veces aparece un elemento, dentro de una secuencia.Ejemplo:
colores="rojo, verde, rojo, negro, azul, rojo"
 colores.count("rojo")
  Resultado: 3
 b. find()
Permite encontrar una cadena de texto dentro de otra, arrojandote el numero de la posición dónde se encuentra.
Ejemplo:
text="Las enzimas son proteinas"
text.find("son")
Resultado:12

 c. isdigit()
sirve para comprobar si todos los caracteres de una cadena de texto son números. Te pondra True si son solo
números, y False si hay algo mas que numeros, como letras o espacios. Ejemplo:
>>> secuencia="1234910"
>>> secuencia.isdigit()
True
>>> numero="1 a b c 2"
>>> numero.isdigit()
False

6. Investigar "fstring": qué son, cómo se usan y un ejemplo. (2.5 puntos)

Un f-string es una forma de escribir textos en Python que permite insertar variables directamente dentro de una cadena de texto.
Para utilizarlo, se coloca una f antes de las comillas y las variables se escriben dentro de llaves {}.
Primero se crean las variables y se les asigna un valor. Después, al utilizar print(), se coloca una f antes del texto
y las variables se escriben entre llaves en el lugar donde queremos que aparezcan.

Ejemplo:
variable = "Superman"
color = "azul"

print(f"{variable} tiene su traje {color}")

Resultado: "Superman tiene su traje azul"

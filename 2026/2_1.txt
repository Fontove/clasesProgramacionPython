6. Investigar "fstring": qué son, cómo se usan y un ejemplo. (2.5 puntos)

Permite colocar variables dentro de una oracion usando una ´f´ y corchetes.
### Nota: tu ejemplo está bien. Solo revisa el nombre: los signos { } que usas, ¿se llaman corchetes? ¿Cómo se llaman los [ ] y cómo los { }?
Se utiliza primero la ´f´ afuera de las comillas de la oracion y a dentro de la oracion se colocan las variables entre corchetes.
ejemplo:
 >>> m="ciencias"
>>> e="plantas"
>>> f"me gustan las {m} y las {e}"

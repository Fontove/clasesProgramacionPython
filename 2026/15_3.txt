1. Investigar cómo se usa el operador módul0o (modulus) en python, explicarlo con sus palabras y poner un ejemplo. (1 punto)
El operador modulus (%) se utiliza para calcular el residuo de una división entre dos (a%b), para saber si un número es par o impar (se utiliza un if y un else, también se le añade doble igual(==)), o para la comprobación de números múltiplos ((a%b), si el resultado da 0 quiere decir que son múltiplos exactos).

Ejemplos:
	*Utilizando if y else
numero=4
if numero % 2 == 0:
    print("Es par")
else:
    print("Es impar")

Es par
	*Utilizado para residuo
print(11%3)

2
(es el residuo de la división).

	*Utilizado para múltiplos
print(10%5)

0
(es un múltiplo de 10 ya que no nos da ningún residuo).

3. Investigar para qué sirve el comando "break" en un for, explicarlo con sus palabras y hacer un ejemplo. (1 punto)
El comando break nos ayuda a "romper" de manera inmediata un loop antes de que este haya completado todas las acciones solicitadas.

Ejemplo:

insectos=["Abeja","Avispa","Mariposa","Polilla","Mantis","Luciernaga","Mariquita"]
for bichito in insectos:
     print(f"Revisando bichito: {bichito}")
     
     if bichito == "Mantis":
        print("¡Lo encontramos! Deteniendo la búsqueda.")
        break
print("Fin del proceso en insectos.")

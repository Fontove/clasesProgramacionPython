# 2. Crear una lista vacía y llenarla con los números pares del 2 al 50 (2,4,6,8,...,48,50) utilizando un for y un condicional para controlar que sólo los pares se agreguen.  (2 puntos)
lista= []
#el ciclo for recorre los números del 2 al 50. El condicional if i%2 == 0 verifica que sea par, ya que el % devuelve el residuo de la división.
#y los numeros pares tienen residuo 0 al dividirse entre 2. 
#si la condición se cumple, los números se agregan a la lista con .append()
for i in range(2,51):
    if i % 2 == 0:
        lista.append(i)
print(lista)

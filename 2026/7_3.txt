1. Investigar cómo se usa el operador módulo (modulus) en python, explicarlo con sus palabras y poner un ejemplo. (1 punto)

El operador módulo (%) se utiliza para obtener el residuo o resto de una división. Su sintaxis es número % divisor. Por ejemplo:
a = 33
b = 10
resultado = a % b
print(resultado)

Salida
3

Esto ocurre porque al dividir 33 entre 10, el cociente es 3 y el residuo es 3.

3. Investigar para qué sirve el comando "break" en un for, explicarlo con sus palabras y hacer un ejemplo. (1 punto)

El comando break sirve para detener inmediatamente un ciclo for, aunque también para while, sin importar que todavía queden iteraciones por realizar.

print(lista)
for i in range(1, 10):
    if i == 4:
        break
    print(i)

Salida
1
2
3

Cuando i vale 4, se ejecuta break y el ciclo termina por completo.

O en el caso de que esté buscando algo y quiero que se detenga el ciclo cuando lo encuentre.

4. Programar el método find de los strings a mano. (2 puntos) Sugerencia: utilizar break cuando encuentren lo que buscan
palabra = 'banana'
# regresar la posición de la primera 'a'

palabra = "banana"

for i in range(len(palabra)):
    if palabra[i] == "a":
        print(i)
        break

Salida
1

range(len(palabra)) genera las posiciones: 0, 1, 2, 3, 4, 5.
palabra[i] obtiene la letra en cada posición.
Cuando encuentra la primera "a", imprime su posición.
break termina el ciclo para que no siga buscando.

4. Explica qué hacen los métodos y da un ejemplo: (2 puntos)
 a. count() sirve para contar cuantas veces aparece una cadena o carácter en un texto. Ejemplo: 
texto = "saraaaaaaa"
resultado = texto.count("a")
print(resultado)
>>>8
 b. find() sirve para buscar una palabra o texto dentro de una cadena y da la posición donde empieza. Por ejemplo:
texto = "Rosa come chetos"
resultado = texto.find("come")
print(resultado)
>>>5
 c. isdigit() sirve para comprobar si una cadena está formada únicamente por números, si es cierto pone True y si no pone False. Por ejemplo:
texto = "987654210"
resultado = texto.isdigit()
print(resultado)
>>>True
texto = "9876rosa210"
resultado = texto.isdigit()
print(resultado)
>>>False
 d. replace() reemplaza una cadena o carácter por otro. Por ejemplo:
texto = "rosa"
resultado = texto.replace("s", "5")
resultado = resultado.replace("a", "4")
print(resultado)
>>>ro54
La s se reemplaza por 5.
Las a se reemplazan por 4.
La r y la o se quedan igual.

6. Investigar "fstring": qué son, cómo se usan y un ejemplo. (2.5 puntos)
Las f-strings son cadenas de texto especiales de Python que permiten insertar variables dentro de un texto usando llaves {}. Se identifican porque llevan una f antes de las comillas. Ejemplo:
nombre = "Rosa"
comida = "chetos"
frase = f"{nombre} come {comida}"
print(frase)
>>>Rosa come chetos
